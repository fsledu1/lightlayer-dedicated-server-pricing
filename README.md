## 便宜的部分省在了哪里

$56 能租到一台整机，省下来的钱主要来自三处。

CPU 是最明显的一处。E3-1230、E5-2660、E5-2670 都是十年前的平台，单核性能放在今天偏弱，多核靠堆核心数撑场面。跑 Nginx、静态站、反代这类吃并发的活没问题，跑编译、转码、单体数据库这种吃单核的任务，会明显感觉到年代感。

存储是第二处。$56 到 $138 这批机器多数是 240G SSD 加 1T HDD 的组合，系统盘是固态，数据盘是机械。机械盘跑 MySQL 的随机读写是短板，真拿来做数据库，得往上选到 960G 或 1T 全 SSD 的机型，价格就跳到 $140 以上。

内存是第三处。8G 和 16G 占满了 $56 这一档，32G 要到 $108，64G 基本落在 $150 以上。拿国内同价位的机器比一下就很清楚：¥460/月 的宁波机房能给到 32G 内存配 480G SSD，¥400/月 的重庆机房甚至给到 64G 加 800G SSD。同样的钱买内存和硬盘，国内机房给得多得多。

那 LightLayer 的钱花在哪？花在境外机位和线路档位上。拿同级别的 E3-1230 比，Hostease 的美国入门款是 $99/月，给 1000M 端口加 10TB 月流量、5 个 IPv4；LightLayer 这台 $56，给的是 50M 起步的端口和不限量。一个买的是端口宽度和流量包，一个买的是低月租和线路可调。你要的是哪一种，决定了这个便宜到底值不值。

## 同一个价签，10M 和 300M 差几十倍

LightLayer 把网络拆成优化、全向、国际三档，同一台机器选不同档位，端口上限跟着变。香港那台 Gold 6138 特价机是 10M 优化 / 15M 全向 / 20M 国际，洛杉矶那台 E5-2660 是 50M 优化 / 200M 全向 / 300M 国际。同一台硬件，最窄和最宽的端口差 30 倍。

“优化”档是对中国大陆访问做过路由优化的线路，几篇促销稿直接把它写成 CN2，官网本身只标优化、全向、国际三档，具体走哪条路由由机房和档位决定。全向档是普通回国方向，国际档面向海外用户。做外贸站、访客主要在欧美，国际档就够；访客在国内，优化档才是关键，端口小一点也得认。

这个口径差异在别处同样存在，只是写法不同。有的商家写“不限流量”，实际是 50M 入、40M 出，超量降速不停机；有的写“10TB 月流量”，跑完就得加钱；还有的把 20M 独享不限量、100M 共享不限量、2T@300Mbps 分成三档卖同一个价。都叫“便宜独服”，买到的端口可能差一个数量级。挑机器前先想清楚峰值要多大端口、访客在哪，再看价签。

## 哪些人不用买独立服务器

个人博客、纯测试环境、流量很小的展示站，继续用 VPS 或云服务器更划算。同品牌自家就有 1C1G 的云机，双十一特价新加坡 $3.5/月、圣何塞 $4.95/月，价格差十倍以上，跑个博客绰绰有余。
